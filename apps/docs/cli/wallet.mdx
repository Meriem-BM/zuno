---
title: zuno wallet
description: List positions held by a wallet.
---

```
zuno wallet positions [owner]
```

Lists Uniswap v3 positions associated with a read-only watch address. Paste an
address in the shell or set `ZUNO_WATCH_ADDRESS` and `ZUNO_CHAIN_ID`.

## Example

```
$ show positions for 0xabc...

  42   WETH / USDC   0.05%   out of range
  77   WETH / USDC   0.05%   in range
```

## Notes

- Output includes a quick range indicator. Use `inspect position <id>` for
  the full snapshot.
- This command does not hit the AXL mesh; it is a direct read.
