title: zuno plan
description: Run the full agent flow and produce a rebalance plan.

```
recommend what I should do with this position
```

The headline workflow. When the AXL mesh is online, the CLI sends the request
through Watcher → Planner → Risk and returns a structured, persisted plan. If
the mesh is not online, the same deterministic planner runs locally so the LP
workflow remains usable.

## What happens

1. CLI sends a `flow_run` envelope to the **Watcher** peer.
2. **Watcher** reads the position + pool tick state, sends a `flow_run`
   to the **Planner** with the position snapshot.
3. **Planner** generates one or two candidate rebalance ranges
   (deterministic, see [Architecture / Agents](/architecture/agents)),
   forwards a `flow_review` to **Risk**.
4. **Risk** scores each candidate, vetoes any with insufficient buffer,
   picks a winner, and emits `flow_run:done` back to the CLI peer.
5. CLI prints the result and writes `~/.zuno/plans/<planId>.json`.

The CLI shows progress events as each agent acts:

```
  ◇ watcher  read       pos_4f2a3b
  ◇ planner  propose
  ◇ risk     critique   2 candidates
```

## Example output

```
$ recommend what I should do with this position

  position    WETH / USDC 0.05%
  range       2,190.79 to 2,421.19   out of range
  current     2,438.19

  recommended 2,273.36 to 2,614.97   shift
  rejected    2,361.41 to 2,519.99   tighten
  reason      less than 36h of buffer at recent volatility

  confidence  0.82  approve_with_caution

  plan id     plan_dd4f9e0b6806
```

## Confidence labels

| label                  | meaning                                          |
|------------------------|--------------------------------------------------|
| `approve`              | clear win, low risk                              |
| `approve_with_caution` | acceptable, but Risk flagged at least one note   |
| `reject`               | no candidate cleared the review                 |
