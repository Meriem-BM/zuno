## Prerequisites

- Node.js LTS
- pnpm 9+
- macOS or Linux

## Install

```bash
git clone <your-fork-url> zuno
cd zuno
pnpm install
```

For live reads, configure a read-only watch address and chain:

```bash
export ZUNO_WATCH_ADDRESS=0x...
export ZUNO_CHAIN_ID=42161
export ZUNO_ARBITRUM_RPC_URL=https://...
export ZUNO_MONITOR_INTERVAL_MS=60000
export ZUNO_AXL_URL=http://localhost:9002
export ZUNO_AXL_CLI_PEER_ID=...
export ZUNO_AXL_WATCHER_PEER_ID=...
export ZUNO_AXL_PLANNER_PEER_ID=...
export ZUNO_AXL_RISK_PEER_ID=...
```

Optional: enable model fallback for loose natural-language intent routing.
The deterministic parser still runs first.

```bash
# Cheap hosted fallback
export ZUNO_INTENT_PROVIDER=groq
export GROQ_API_KEY=...
export ZUNO_INTENT_MODEL=llama-3.1-8b-instant

# Useful when validating provider errors
export ZUNO_DEBUG_INTENTS=true
```

## Manual: four terminals

If you want to watch each agent independently:

```bash
# terminal 1
axl

# terminal 2
pnpm watcher

# terminal 3
pnpm planner

# terminal 4
pnpm risk
```

Then, in a fifth terminal:

```bash
pnpm cli
```

Inside the shell:

```
analyze wallet 0x...
show positions for 0x...
inspect position 42
recommend what I should do with this position
show me the diff
simulate it
apply it
```

For live monitoring, run the worker in a separate terminal:

```bash
pnpm monitor
```

The worker writes local alerts to `~/.zuno/alerts.json`. In the shell, use:

```
show alerts
watch my wallet
```

## AXL

Zuno expects real AXL nodes. Configure the local node URL and each role's peer id:

```bash
export ZUNO_AXL_URL=http://localhost:9002
export ZUNO_AXL_CLI_PEER_ID=...
export ZUNO_AXL_WATCHER_PEER_ID=...
export ZUNO_AXL_PLANNER_PEER_ID=...
export ZUNO_AXL_RISK_PEER_ID=...
```
